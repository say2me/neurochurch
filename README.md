# Нейроцерковь

Сатирический арт-проект об ИИ на чистом JavaScript: атмосферный манифест, видео-мемы и ссылки на шесть соцсетей.

## Структура

- `app.js` — создание страницы через DOM API.
- `content.js` — содержимое манифеста.
- `styles.js` — стили и адаптивная вёрстка.
- `community.js` — видео, происхождение мема и ссылки на соцсети.
- `social-styles.js` — адаптивные стили разделов видео и соцсетей.
- `media/` — собственный ролик, обложка и русские субтитры.
- `index.html` — точка входа.
- `sanctum.png` — иллюстрация.

## Локальный просмотр

Запустите `python3 -m http.server 8000` в папке проекта и откройте http://localhost:8000.

## Публикация

GitHub Pages публикует корень ветки `main`. Изменения в этой ветке автоматически обновляют сайт.

## Видео и источники

Первый выпуск — собственный анимированный комикс по мотивам «This is fine / On Fire» (KC Green, 9 января 2013). [Оригинал](https://gunshowcomic.com/648). Панели оригинального комикса не используются; иллюстрации созданы ИИ. Сюжет вымышленный.
