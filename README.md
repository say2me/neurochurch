# Нейроцерковь

Атмосферный манифест цифровой религии на чистом JavaScript.

## Структура

- `app.js` — создание страницы через DOM API.
- `content.js` — содержимое манифеста.
- `styles.js` — стили и адаптивная вёрстка.
- `index.html` — точка входа.
- `sanctum.png` — иллюстрация.

## Локальный просмотр

Запустите `python3 -m http.server 8000` в папке проекта и откройте http://localhost:8000.

## Публикация

GitHub Pages публикует корень ветки `main`. Изменения в этой ветке автоматически обновляют сайт.
