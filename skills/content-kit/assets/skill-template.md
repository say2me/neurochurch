# Название специализации

Результат: какой готовый материал создаётся.
Вход: какие данные нужны из запроса, плана и материалов.

## Работа

- Прочитать применимые ограничения из references/constraints.md.
- Заполнить assets/content-brief.md.
- Выполнить только особенности этого формата: например, разные первые кадры для Shorts и TikTok.
- Создать файлы, проверить критерии ниже и сохранить точный статус.

## Критерии готовности

Указать 2–4 наблюдаемых результата: например, ролик воспроизводится, субтитры читаемы на телефоне, источник проверен, CTA ведёт на заданный сайт.

## Границы

Генерация не даёт нового разрешения на внешние действия. Использовать уже разрешённый процесс публикации; не расширять его.

При создании скилла заменить все поясняющие поля и имя, удалить этот абзац. Скопировать нужные references/constraints.md и assets/content-brief.md в новый пакет; исключить правила чужого проекта. Сохранить основной файл коротким.
